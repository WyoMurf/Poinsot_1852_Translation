
This project comprises some work between Gemini AI and myself. The original text was
from the Google Gutenburg archives. The illustrations were derived from the Dartmouth
archives, because Google didn't capture the plates that are folded up in the book
it scanned. Gemini did the translation from French to English. It extracted the equations
into an OpenOffice/LibreOffice math format. The .odt file is the end result.

It is not perfect. There could exist lots of bugs. But I can understand this translation
a lot better than the French! 

Why did I do this? Well, as a learning experience with AI, and also, I desire to learn
more about the math behind rotational dynamics. Also, there may exist other translations,
just couldn't find them.

Let me know about glaring omissions and errors. I'll see if I can fix them!
